# python-kiosk-manager

A simple command-line kiosk management system built with Python.

I built this project to practise using Python to handle a small business scenario involving **inventory, sales, and basic reporting**.

## What the Program Does

* View available stock
* Add new products
* Restock existing products
* Sell products and update inventory
* Check stock availability before a sale
* Record sales
* Calculate total sales revenue
* Identify the best-selling product
* Track unique products sold
* Search for products using partial names
* Validate user input

## Python Concepts Used

* Variables and data types
* `if / elif / else`
* `while` and `for` loops
* Functions
* Dictionaries
* Lists
* Tuples
* Sets
* String methods
* Input validation
* Formatted output

## Data & Business Logic

The project uses a dictionary to manage inventory, a list to store sales, tuples to represent individual sales, and a set to track unique products sold.

I also used accumulators and loops to calculate sales totals and identify the best-selling product.

Building the project helped me understand how individual Python concepts can be combined to solve a practical business problem rather than being used only in isolated exercises.

## Running the Project

Clone the repository and run:

```bash
python kiosk_manager.py
```

The program runs in the terminal and guides the user through the available options.
